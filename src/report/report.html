Report a problem

Tell us what went wrong and we will look into it. Reports are posted on GitHub, the website where TUI Navigator's problems are tracked. Nothing leaves your computer until you press the last button there yourself.

1 What happened?

A sentence or two is enough: what you pressed, and what you expected to happen.

2 On which page?

It goes in the report's title, so we can open the same page.

Reports on GitHub are public. If the address has something private in it, shorten it: for example, keep only mail.google.com.

3 What else goes in the report

  • The extension's log from this page: its last 20 events, with the time of each, the keys it acted on and the elements it moved between, described by their shape (tag, a few class names, position). No text, labels or links from the page. Admin mode is on, so this log also holds element ids, labels, links and their opening tags.
  • The extension version, your browser's version string and the window size.

The extension keeps this log only in the page's memory, and only the last 20 events. Reloading the page clears it.

4 A copy of the page (optional)

It helps us most when a problem is hard to repeat. It takes one more step: a file is saved to your computer, and you drag it into the GitHub page yourself.

The copy holds everything on the page: message text, file names, anything you are signed in to. Include it only if nothing on the page is private. Chrome asks for permission the first time.

5 Send it

When you press the button below:

  1. GitHub opens in a new tab, with your report already written in it.
  2. If GitHub asks you to sign in, sign in, or create a free account. This is needed only the first time.
  3. Drag the file tui-report-….zip into the big text box on GitHub. Chrome shows the file at the top right of the window, under the download arrow; it is also in your Downloads folder.
  4. Press the green Create button at the bottom of the GitHub page. That is the moment the report is sent.

If you created a GitHub account on the way, your report may not be there any more. Press Open GitHub again and it will be written in again, with any changes you made here.
