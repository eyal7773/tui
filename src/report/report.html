This may send personal information!

The copy holds everything on the page: names, email addresses, messages, account details, whatever is on screen. Untick the box if anything there is private.

What is sent

Your description, the page's address (), the extension version, your browser's version string and the window size, and the extension's log from this page, exactly as below. The log has no text, labels or links from the page. Admin mode is on, so the log also holds element ids, labels, links and their opening tags. With the box ticked, a copy of the page goes too. It is sent to the TUI Navigator report server, kept there only until the developer downloads it, and then deleted. It is not made public.
