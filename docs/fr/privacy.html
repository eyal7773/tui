Confidentialité

TUI Navigator n’envoie rien nulle part. Ce qu’il conserve reste sur votre ordinateur, et un rapport de bug n’en sort que lorsque vous l’envoyez vous-même.

Ce qu’il conserve, sur votre ordinateur

  • Vos réglages : la couleur et l’épaisseur de l’anneau, le défilement, les sites où vous l’avez désactivé et si vous voulez le récapitulatif hebdomadaire. Conservés dans le stockage des extensions de Chrome.
  • Vos compteurs d’utilisation : combien de fois vous avez appuyé sur chaque touche à laquelle l’extension réagit, par jour et par heure, pour la page de statistiques et le récapitulatif hebdomadaire. Des nombres seulement : ni adresses, ni contenu des pages. Conservés dans le stockage des extensions de Chrome.
  • Un court journal de ce que l’extension a fait sur la page où vous êtes : les touches auxquelles elle a réagi (flèches, Enter, Home/End, F10, Esc) et les éléments entre lesquels elle s’est déplacée, décrits seulement par leur forme : balise, rôle, quelques noms de classe, position et taille. Il ne conserve jamais le texte de la page, les libellés, les liens, les identifiants ni rien de ce que vous tapez. Il garde les 20 derniers événements, n’existe que dans la mémoire de cette page et disparaît quand elle est rechargée ou fermée.

Ce qu’il envoie

Rien, sauf si vous envoyez un rapport de bug (voir plus bas). En dehors d’un rapport, la seule requête qu’il fait concerne une feuille de style : la page de statistiques charge le CSS de Bootstrap depuis cdn.jsdelivr.net, ce qui, comme toute requête web, montre votre adresse IP à ce serveur.

Rapports de bug

F10 → Report a problem ouvre une fenêtre où vous décrivez ce qui s’est passé. Le rapport contient votre description, l’adresse complète de la page (prise dans l’onglet et reprise dans le titre du rapport), le journal ci-dessus, la version de l’extension, celle du navigateur et la taille de la fenêtre ; What is sent, sous les boutons, montre tout cela.

Rien n’est envoyé avant que vous appuyiez sur Send report. Le rapport part alors, sous forme d’un seul fichier zip, vers le serveur de rapports de TUI Navigator (hébergé sur Cloudflare, à l’adresse tui-reports.taliandeyal.workers.dev). Il n’y est conservé que jusqu’à ce que le développeur le télécharge, puis il est supprimé du serveur. Les rapports ne sont pas rendus publics, et aucun compte, nom ni adresse e-mail n’est demandé ou envoyé. Comme toute requête web, l’envoi montre votre adresse IP au serveur ; elle sert seulement à limiter le nombre de rapports qu’une adresse peut envoyer par minute et n’est pas conservée avec le rapport.

Attach a copy of the page est coché d’emblée. Cette copie contient tout ce qui se trouve sur la page : décochez-la s’il y a quelque chose de privé. La première fois que vous envoyez avec cette option cochée, Chrome vous demande l’autorisation pageCapture ; sans elle, le rapport part sans la copie.

Autorisations

  • storage : vos réglages et compteurs d’utilisation.
  • activeTab : les réglages de la petite fenêtre pour le site où vous êtes.
  • notifications, alarms : le récapitulatif hebdomadaire, que vous pouvez désactiver.
  • pageCapture (facultative, demandée seulement quand vous joignez une copie de la page à un rapport) : faire cette copie.
  • Accès à tous les sites : les flèches doivent fonctionner partout où vous naviguez.
