TUI Navigator vous permet de naviguer sur n’importe quel site avec les flèches du clavier. La main reste sur le clavier, et le poignet, l’avant-bras et l’épaule se reposent.

Bientôt sur le Chrome Web Store

pourquoi je l’ai créée

ce qu’elle épargne à votre corps

La souris garde la main crispée, le poignet plié et le bras tendu sur le côté. Avec les flèches, les mains restent là où elles tapent. Voici à peu près ce qu’une semaine normale de navigation avec l’extension épargne à votre corps.

Cette semaine est un exemple, pas les données de quelqu’un : cinq jours de travail, avec environ 80 liens ouverts et 400 appuis sur les flèches par jour. La page de statistiques de l’extension affiche la même figure pour votre propre navigation, calculée sur votre ordinateur et jamais envoyée nulle part.

résultats pour « navigation au clavier »

C’est une maquette, pas l’extension, mais l’anneau est le vrai. Cliquez sur une ligne, puis appuyez sur ↓ ↑ ← →.

touches

↓ ↑
Aller à l’élément au-dessus ou en dessous.
← →
Se déplacer le long de la rangée où vous êtes.
Home End
Sauter à l’une des extrémités de la ligne où vous êtes. La dernière flèche utilisée décide de ce qu’est une ligne : après un déplacement latéral, c’est la rangée ; après un déplacement vertical, c’est la colonne.
Enter
Activer l’élément sélectionné. Sur une zone de texte ou une liste déroulante, le focus lui est confié pour que vous puissiez taper ou choisir. Sur une ligne de liste, c’est le lien qu’elle contient qui est activé, car c’est là que la ligne garde son adresse.
Esc
Quitter une zone de texte et revenir à la navigation dans la page.
Esc à nouveau
Rendre le clavier au site pour que ses propres raccourcis fonctionnent : la barre d’espace pour lire une vidéo, ou toute autre touche qu’il utilise. Appuyez encore une fois pour reprendre la navigation.
F10
Ouvrir le menu : dupliquer la page, revenir en arrière, sélectionner du texte, signaler un problème ou voir toutes les touches. Esc le ferme.

comment ça marche

L’extension lit la page, repère les éléments où il vaut la peine de s’arrêter et les traite comme une grille. Les flèches passent de l’un à l’autre selon leur position à l’écran et non selon l’ordre du code : la flèche droite va à ce qui se trouve à droite, pas à ce qui vient ensuite dans le HTML.

Les touches sont interceptées avant que la page ne les voie, si bien que les sites qui ont leurs propres raccourcis fléchés ne vous disputent pas le contrôle. Les zones de texte, les listes déroulantes et tout ce qui a besoin des flèches pour lui-même sont laissés tranquilles jusqu’à ce que vous leur donniez le focus avec Enter.

La petite fenêtre de l’icône dans la barre d’outils compte vos actions et renvoie à une page de statistiques. Quand quelque chose ne va pas, F10 → Report a problem affiche un court journal de ce que l’extension a fait sur la page et l’envoie au développeur avec votre description. Rien n’est envoyé avant que vous appuyiez sur Send report ; voir la page confidentialité.
