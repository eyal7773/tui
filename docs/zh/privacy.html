隐私

TUI Navigator 不会把任何东西发送到任何地方。它保存的内容都留在你的电脑上，错误报告只有在你亲自发送时才会离开。

它在你的电脑上保存什么

  • 你的设置：光环的颜色和粗细、滚动方式、你关闭了扩展的网站，以及是否需要每周回顾。保存在 Chrome 的扩展存储中。
  • 你的使用次数：你按下扩展所响应的每个键的次数，按天和小时统计，用于统计页面和每周回顾。只有数字：没有网址，也没有页面内容。保存在 Chrome 的扩展存储中。
  • 扩展在当前页面所做操作的简短日志：它响应过的按键（方向键、Enter、Home/End、F10、Esc），以及它在哪些元素之间移动，只按形态描述：标签、角色、几个类名、位置和大小。它从不保存页面上的文字、标签文本、链接、ID 或你输入的任何内容。它只保留最近 20 个事件，只存在于该页面的内存中，页面重新加载或关闭后即消失。

它发送什么

什么都不发送，除非你发送错误报告（见下文）。

错误报告

F10 → Report a problem 会打开一个窗口，让你写下发生了什么。报告包含你的描述、页面的完整网址（取自标签页，并放在报告标题中）、上面提到的日志、扩展版本、浏览器版本和窗口大小；按钮下方的 What is sent 会显示全部内容。

在你按下 Send report 之前，什么都不会发送。之后，报告会作为一个 zip 文件发送到 TUI Navigator 的报告服务器（运行在 Cloudflare 上，地址为 tui-reports.taliandeyal.workers.dev）。它只保存到开发者下载为止，随后从服务器删除。报告不会公开，也不会要求或发送任何账号、姓名或电子邮件地址。和任何网络请求一样，发送时服务器会看到你的 IP 地址；它只用于限制每个地址每分钟可发送的报告数量，不会与报告一起保存。

Attach a copy of the page 默认是勾选的。这份副本包含页面上的全部内容，如果其中有隐私信息，请取消勾选。第一次在勾选状态下发送时，Chrome 会向你申请 pageCapture 权限；没有这个权限，报告会在不附带副本的情况下发送。

权限

  • storage：你的设置和使用次数。
  • activeTab：在小窗口中针对当前网站的设置。
  • notifications、alarms：每周回顾，可以关闭。
  • pageCapture（可选，只在你把页面副本附加到报告时申请）：用于制作该副本。
  • 访问所有网站：方向键需要在你浏览的任何地方都能用。
