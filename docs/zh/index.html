我为什么做这个

它为你的身体省下了什么

使用鼠标时，手要一直握着，手腕弯曲，手臂伸向一侧。用方向键时，双手留在打字的位置。下面大致展示了用这个扩展正常浏览一周，能为身体省下多少。

这一周只是示例，不是任何人的真实数据：五个工作日，每天打开约 80 个链接、按约 400 次方向键。扩展的统计页面会按你自己的浏览情况显示同样的图示，数据只在你的电脑上计算，不会发送到任何地方。

“键盘导航”的搜索结果

这是演示，不是扩展本身，但这个光环和扩展里的一模一样。点击一行，然后按 ↓ ↑ ← →。

按键

↓ ↑
移到上方或下方的元素。
← →
沿当前所在的行移动。
Home End
跳到当前这条线的任一端。最后按的方向键决定“线”指什么：横向移动之后是行，纵向移动之后是列。
Enter
激活当前选中的元素。在文本框或下拉列表上，会把焦点交给它，方便你输入或选择。在列表的一行上，会激活行里的链接，因为行的地址保存在那里。
Esc
离开文本框，回到页面导航。
Esc 再按一次
把键盘交还给网站，让它自己的快捷键生效，比如用空格播放视频，或网站设定的其他按键。再按一次即可继续导航。
F10
打开菜单：复制页面、后退、选择文字、报告问题，或查看所有按键。按 Esc 关闭。

工作原理

扩展会读取页面，找出值得停留的元素，并把它们当作网格。方向键按元素在屏幕上的位置移动，而不是按代码顺序，所以按右键会去到右边的东西，而不是 HTML 中恰好排在后面的元素。

按键会在页面收到之前被截获，所以自带方向键快捷键的网站不会和你抢控制权。文本框、下拉列表以及其他需要方向键的控件会保持原样，直到你用 Enter 把焦点交给它们。

工具栏图标打开的小窗口会统计你的操作次数，并链接到统计页面。出问题时，F10 → Report a problem 会显示扩展在这个页面上所做操作的简短日志，并连同你的描述一起发送给开发者。在你按下 Send report 之前，什么都不会发送；详见隐私页面。
