Datenschutz

TUI Navigator sendet nichts irgendwohin. Was es speichert, bleibt auf Ihrem Computer, und ein Fehlerbericht verlässt ihn nur, wenn Sie ihn selbst senden.

Was auf Ihrem Computer gespeichert wird

  • Ihre Einstellungen: Farbe und Stärke des Rings, Scrollverhalten, die Websites, auf denen Sie es ausgeschaltet haben, und ob Sie den Wochenrückblick möchten. Gespeichert im Erweiterungsspeicher von Chrome.
  • Ihre Nutzungszahlen: wie oft Sie jede Taste gedrückt haben, auf die die Erweiterung reagiert, nach Tag und Stunde, für die Statistikseite und den Wochenrückblick. Nur Zahlen: keine Adressen, keine Seiteninhalte. Gespeichert im Erweiterungsspeicher von Chrome.
  • Ein kurzes Protokoll dessen, was die Erweiterung auf der aktuellen Seite getan hat: die Tasten, auf die sie reagiert hat (Pfeile, Enter, Home/End, F10, Esc), und die Elemente, zwischen denen sie gewechselt ist, beschrieben nur nach ihrer Form: Tag, Rolle, einige Klassennamen, Position und Größe. Es enthält nie den Text der Seite, Beschriftungen, Links, IDs oder etwas, das Sie eingeben. Es hält die letzten 20 Ereignisse, existiert nur im Speicher dieser Seite und verschwindet, wenn die Seite neu geladen oder geschlossen wird.

Was gesendet wird

Nichts, es sei denn, Sie senden einen Fehlerbericht (siehe unten). Abgesehen von einem Bericht stellt die Erweiterung nur eine Anfrage, nach einem Stylesheet: Die Statistikseite lädt das CSS von Bootstrap von cdn.jsdelivr.net, wodurch dieser Server, wie bei jeder Webanfrage, Ihre IP-Adresse sieht.

Fehlerberichte

F10 → Report a problem öffnet ein Fenster, in dem Sie beschreiben, was passiert ist. Der Bericht enthält Ihre Beschreibung, die vollständige Adresse der Seite (aus dem Tab übernommen und in den Titel des Berichts gesetzt), das oben beschriebene Protokoll, die Version der Erweiterung, die Browserversion und die Fenstergröße; What is sent unter den Schaltflächen zeigt all das an.

Nichts wird gesendet, bevor Sie Send report drücken. Dann geht der Bericht als eine einzige ZIP-Datei an den Berichtsserver von TUI Navigator (betrieben auf Cloudflare unter tui-reports.taliandeyal.workers.dev). Er wird dort nur so lange aufbewahrt, bis der Entwickler ihn herunterlädt, und dann vom Server gelöscht. Berichte werden nicht veröffentlicht, und es wird weder ein Konto noch ein Name noch eine E-Mail-Adresse abgefragt oder gesendet. Wie bei jeder Webanfrage sieht der Server beim Senden Ihre IP-Adresse; sie dient nur dazu, zu begrenzen, wie viele Berichte eine Adresse pro Minute senden kann, und wird nicht mit dem Bericht gespeichert.

Attach a copy of the page ist von Anfang an angehakt. Diese Kopie enthält alles, was auf der Seite steht; entfernen Sie den Haken, wenn dort etwas Privates ist. Wenn Sie zum ersten Mal mit gesetztem Haken senden, fragt Chrome nach der Berechtigung pageCapture; ohne sie geht der Bericht ohne die Kopie.

Berechtigungen

  • storage: Ihre Einstellungen und Nutzungszahlen.
  • activeTab: die Einstellungen im kleinen Fenster für die Website, auf der Sie sind.
  • notifications, alarms: der Wochenrückblick, den Sie ausschalten können.
  • pageCapture (optional, nur angefragt, wenn Sie einem Bericht eine Kopie der Seite beilegen): diese Kopie erstellen.
  • Zugriff auf alle Websites: Die Pfeiltasten müssen überall funktionieren, wo Sie surfen.
