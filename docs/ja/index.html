マウスを減らして、
痛みを減らす。

TUI Navigator を使えば、どんなウェブサイトも矢印キーで操作できます。手はキーボードの上にとどまり、手首・前腕・肩が休まります。

まもなく Chrome ウェブストアで公開

これを作った理由

体への負担がどれだけ減るか

マウスを使うと、手は握ったまま、手首は曲がったまま、腕は横に伸びたままになります。矢印キーなら、両手はタイピングの位置にとどまります。この拡張機能でふつうに一週間ブラウジングすると、体の負担がおおよそこれだけ減ります。

この一週間は例であり、誰かの実データではありません。5 日間の勤務で、1 日あたり約 80 件のリンクを開き、矢印キーを約 400 回押した場合です。拡張機能の統計ページでは、あなた自身のブラウジングで同じ図が表示されます。集計はあなたのパソコン上で行われ、どこにも送信されません。

試してみる

「キーボード操作」の検索結果

これは模型で、拡張機能そのものではありませんが、リングは本物と同じです。行をクリックしてから ↓ ↑ ← → を押してください。

キー

↓ ↑
上または下の要素へ移動します。
← →
いまいる行に沿って移動します。
Home End
いまいるラインの端へジャンプします。最後に押した矢印キーで「ライン」の意味が決まります。横に動いたあとなら行、縦に動いたあとなら列です。
Enter
選択中の要素を実行します。テキストボックスやドロップダウンでは、入力や選択ができるようフォーカスを渡します。リストの行では、行の中のリンクを実行します。行のリンク先はそこに入っているからです。
Esc
テキストボックスを抜けて、ページの操作に戻ります。
Esc もう一度
キーボードをサイトに返し、サイト独自のショートカットが使えるようにします。スペースで動画を再生するなど、サイトが割り当てたキーです。もう一度押すと操作を再開します。
F10
メニューを開きます：ページの複製、戻る、テキストの選択、問題の報告、すべてのキーの一覧。Esc で閉じます。

しくみ

拡張機能はページを読み取り、立ち止まる価値のある要素を見つけて、それらをグリッドとして扱います。矢印キーはコードの順番ではなく画面上の位置で要素間を移動するので、右矢印は右にあるものへ移動し、HTML でたまたま次に書かれているものへは移動しません。

キー入力はページに届く前に受け取られるため、独自の矢印キーショートカットを持つサイトと操作を取り合うことはありません。テキストボックスやドロップダウンなど矢印キーを自分で使う要素は、Enter でフォーカスを渡すまでそのままにしておきます。

ツールバーのアイコンから開く小さなウィンドウは、あなたの操作回数を数え、統計ページへのリンクを表示します。うまくいかないときは、F10 → Report a problem で拡張機能がそのページで行ったことの短いログが表示され、あなたの説明と一緒に開発者へ送られます。Send report を押すまでは何も送信されません。詳しくはプライバシーのページをご覧ください。
