プライバシー

TUI Navigator はどこにも何も送信しません。保存するものはあなたのパソコンに残り、バグ報告はあなた自身が送ったときだけ外へ出ます。

あなたのパソコンに保存するもの

  • 設定：リングの色と太さ、スクロール、拡張機能をオフにしたサイト、週ごとのまとめを受け取るかどうか。Chrome の拡張機能用ストレージに保存されます。
  • 使用回数：拡張機能が反応する各キーを押した回数を、日・時間ごとに記録します。統計ページと週ごとのまとめに使われます。数値のみで、アドレスやページの内容は含みません。Chrome の拡張機能用ストレージに保存されます。
  • いまのページで拡張機能が行ったことの短いログ：反応したキー（矢印、Enter、Home/End、F10、Esc）と、移動した要素。要素は形だけで記述されます：タグ、ロール、いくつかのクラス名、位置とサイズ。ページ上のテキスト、ラベル、リンク、id、入力した内容は一切保存しません。直近 20 件のイベントだけを、そのページのメモリ上にのみ保持し、ページを再読み込みするか閉じると消えます。

送信するもの

バグ報告（下記）を送らない限り、何も送信しません。

バグ報告

F10 → Report a problem を選ぶと、何が起きたかを書くウィンドウが開きます。報告には、あなたの説明、ページの完全なアドレス（タブから取得し、報告のタイトルに入ります）、上記のログ、拡張機能のバージョン、ブラウザーのバージョン、ウィンドウのサイズが含まれます。ボタンの下の What is sent にすべてが表示されます。

Send report を押すまでは何も送信されません。押すと、報告は 1 つの zip ファイルとして TUI Navigator の報告サーバー（Cloudflare 上の tui-reports.taliandeyal.workers.dev）へ送られます。開発者がダウンロードするまでだけそこに保存され、その後サーバーから削除されます。報告は公開されず、アカウント、名前、メールアドレスを求めたり送ったりすることもありません。他のウェブリクエストと同様に、送信時にはサーバーにあなたの IP アドレスが見えます。これは 1 つのアドレスが 1 分間に送れる報告の数を制限するためだけに使われ、報告と一緒には保存されません。

Attach a copy of the page は最初からチェックされています。このコピーにはページ上のすべてが含まれるので、非公開の内容があればチェックを外してください。チェックしたまま初めて送るとき、Chrome が pageCapture の権限を求めます。許可しない場合、報告はコピーなしで送られます。

権限

  • storage：設定と使用回数。
  • activeTab：小さなウィンドウでの、いま開いているサイト向けの設定。
  • notifications、alarms：週ごとのまとめ（オフにできます）。
  • pageCapture（任意。報告にページのコピーを添えるときだけ求めます）：そのコピーの作成。
  • すべてのサイトへのアクセス：どこを閲覧していても矢印キーが使えるようにするためです。
