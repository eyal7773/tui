Privacy

TUI Navigator sends nothing anywhere. What it keeps stays on your computer, and a bug report leaves it only when you send one yourself.

What it keeps, on your computer

  • Your settings: ring colour and thickness, scrolling, the sites you turned it off on, and whether you want the weekly recap. Kept in Chrome's extension storage.
  • Your usage counts: how many times you pressed each key the extension acts on, by day and hour, for the stats page and the weekly recap. Counts only: no addresses, no page content. Kept in Chrome's extension storage.
  • A short log of what the extension did on the page you are on: the keys it acted on (arrows, Enter, Home/End, F10, Esc) and the elements it moved between, described by their shape: tag, role, a few class names, position and size. It never holds the text on the page, labels, links, ids, or anything you type. It holds the last 20 events, lives only in that page's memory, and is gone when the page is reloaded or closed.

What it sends

Nothing. The extension has no server and sends no data. The one request it makes is for a stylesheet: the stats page loads Bootstrap's CSS from cdn.jsdelivr.net, which, like any web request, shows that server your IP address.

Bug reports

F10 → Report a problem opens a window that shows everything the report will hold: your description, the page's address (in a box you can edit, since it goes in the report's title), the log above, the extension version, your browser version and the window size.

Continue to GitHub opens a new issue on GitHub with all of that written in. The extension sends nothing: the report reaches GitHub only if you post the issue yourself. GitHub issues are public, and GitHub's own privacy policy covers what you post there.

You may tick Include a copy of the page. That copy holds everything on the page, so it is off unless you turn it on, and Chrome asks you for the pageCapture permission the first time. It is saved as a zip in your downloads, and goes to GitHub only if you drag it into the issue. Only save the report as a file saves the zip without going to GitHub.

Permissions

  • storage: your settings and usage counts.
  • activeTab: the popup's settings for the site you are on.
  • notifications, alarms: the weekly recap, which you can turn off.
  • pageCapture (optional, asked for only when you include a copy of the page in a report): saving that copy.
  • Access to every site: the arrow keys have to work wherever you browse.
